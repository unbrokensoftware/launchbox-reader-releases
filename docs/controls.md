# Keyboard and Controller Controls

LaunchBox Reader supports mouse, keyboard, and controller navigation.

## Keyboard Defaults

| Action | Default |
| --- | --- |
| Close reader | Escape |
| Toggle chrome | M |
| Toggle fullscreen | F |
| Back | Backspace |
| Focus chrome | Tab |
| Previous page | Left |
| Next page | Right, Space |
| Jump backward 5% | Page Up |
| Jump forward 5% | Page Down |
| Open contents | T |
| Open settings | S |
| Toggle bookmark | B |
| Zoom out | Minus |
| Zoom in | Plus |
| Move overlay selection up | Up |
| Move overlay selection down | Down |
| Move overlay selection left | Left |
| Move overlay selection right | Right |
| Activate overlay selection | Enter, Space |

In continuous EPUB mode, Up and Down step-scroll, while Left, Right, and Space page-scroll.
In stacked fixed-layout mode, the arrow keys follow the stack direction: vertical stacks use Up/Down for step scroll and Left/Right for page scroll, while horizontal stacks swap those directions.

## Chrome Navigation

When the reader chrome is visible you can move focus through the chrome buttons with Tab, Shift+Tab, Left, or Right. Press Enter or Space to activate the focused button. Press Back or the controller B button to hide the chrome and return focus to the document.

## Back vs Close

Back and Close are intentionally different.

Back returns from the current UI layer:

- From Settings or Contents back to the reader chrome.
- From reader chrome back to the document.

Close exits the reader.

## Custom Mappings

Mappings can include:

- Single-button or single-key inputs.
- Multi-button combinations.
- Long-press mappings.
- More than one mapping for the same action.

Use Clear to remove mappings from an action. Use Reset to restore defaults after an action has been cleared.

## Tips

- If you read mostly with a controller, make sure Back and Close are comfortable and hard to trigger accidentally.
- Use long press for actions that should not happen by mistake.
- Keep page navigation on easy-to-reach buttons.
- Keep Settings and Contents on buttons you can remember quickly.
