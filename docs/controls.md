# Keyboard and Controller Controls

LaunchBox Reader supports mouse, keyboard, and controller navigation.

## Keyboard Defaults

| Action | Default |
| --- | --- |
| Close reader | Escape |
| Toggle chrome | M |
| Toggle fullscreen | F |
| Back | Backspace |
| Focus chrome | Tab |
| Previous page | Left, Page Up |
| Next page | Right, Page Down, Space |
| Open contents | T |
| Open settings | S |
| Toggle bookmark | B |
| Zoom out | Minus |
| Zoom in | Plus |
| Move overlay selection up | Up |
| Move overlay selection down | Down |
| Activate overlay selection | Enter, Space |

## Controller Defaults

Controller names are shown using common Xbox-style labels. Other controllers may display equivalent labels depending on the device.

| Action | Default |
| --- | --- |
| Close reader | Select + Start |
| Toggle chrome | Y |
| Toggle fullscreen | Right stick button |
| Back / cancel overlay | B |
| Previous page | Left shoulder |
| Next page | Right shoulder |
| Open contents | Back |
| Open settings | Start |
| Toggle bookmark | X |
| Zoom out | Left trigger |
| Zoom in | Right trigger |
| Cycle fit mode | Left stick button |
| Analog scroll | Left stick |
| Move overlay focus | D-pad or left stick |
| Confirm overlay selection | A |
| Begin progress scrub | D-pad up or D-pad down |
| Confirm progress target | A |
| Cancel progress scrub | B |

## Back vs Close

Back and Close are intentionally different.

Back returns from the current UI layer:

- From Settings or Contents back to the reader chrome.
- From reader chrome back to the document.

Close exits the reader.

## Custom Mappings

Mappings can include:

- Single-button or single-key inputs.
- Multi-button combinations.
- Long-press mappings.
- More than one mapping for the same action.

Use Clear to remove mappings from an action. Use Reset to restore defaults after an action has been cleared.

## Tips

- If you read mostly with a controller, make sure Back and Close are comfortable and hard to trigger accidentally.
- Use long press for actions that should not happen by mistake.
- Keep page navigation on easy-to-reach buttons.
- Keep Settings and Contents on buttons you can remember quickly.
