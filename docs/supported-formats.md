# Supported Formats

LaunchBox Reader supports common document, ebook, comic, archive, image, and text formats.

## Documents and Books

- PDF
- EPUB
- DOCX (Word)
- TXT
- RTF

Word, text, and rich text documents are reflowable. They are laid out as
pages with chapters and a table of contents, and they respond to the font,
text size, line spacing, and margin settings in the same way EPUB books do.

Older `.doc` Word files are not supported. Open the file in Word or a
compatible editor and save it as `.docx` to read it here.

## Comics and Image Archives

- CBZ
- CBR
- CB7
- CBT
- ZIP
- RAR
- 7Z

## Images and Image Folders

- JPG
- JPEG
- PNG
- GIF
- BMP
- WEBP
- Folders containing supported image files

## Best Results

For scanned manuals and comics, use PDF or comic archive formats when possible. For loose page images, place the images in a folder or archive with filenames that sort in reading order.

Examples:

- `Manual - Page 001.png`
- `Manual - Page 002.png`
- `Manual - Page 003.png`

## If a File Does Not Open

Check that:

- The file exists and is not blocked by Windows.
- The file is not password protected.
- The archive is not damaged.
- Image files inside an archive are named in the order you expect.
- The format is listed above.

See [Troubleshooting](troubleshooting.html) for more help.
