# Getting Started

LaunchBox Reader opens documents, books, comics, archives, images, and image folders. It is meant for manuals, strategy guides, reference cards, magazines, comics, art books, and other documents you want to read quickly and comfortably.

## What It Is For

Use LaunchBox Reader when you want to:

- Read a manual, guide, book, or reference document.
- View scanned booklets, maps, magazines, or art books.
- Read comics, scanned booklets, or image archives.
- Open EPUB books and text documents.
- Resume a document at the exact place you stopped reading.
- Navigate comfortably from a couch with a controller.

## Opening a Document

Open a supported file or image folder with LaunchBox Reader. Documents can include PDFs, EPUB books, comic archives, image archives, text files, and folders of page images.

The reader remembers document state, including your last location and many display preferences.

## First Launch

The first time a large document opens, LaunchBox Reader prioritizes the page you need first and continues preparing the rest of the document in the background. This helps manuals, PDFs, comics, and image archives appear quickly instead of making you wait for the entire file to be processed up front.

## The Reader Window

The reader is built around the document itself. Controls stay out of the way until you need them.

The top chrome gives quick access to:

- Close reader
- Table of contents and bookmarks
- Settings
- Zoom
- Fullscreen

Some documents also show a progress control so you can move through the document quickly.

## Resuming

When you reopen a document, LaunchBox Reader returns to the page or location you were reading. It does this before showing the document so you do not see the reader open on page one and then jump.
