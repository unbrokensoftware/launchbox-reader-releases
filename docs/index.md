# LaunchBox Reader Documentation

Welcome to the public documentation for LaunchBox Reader.

## Getting Started

LaunchBox Reader opens supported document formats from LaunchBox and Big Box, including manuals, guides, comics, image folders, EPUB books, and text documents.
