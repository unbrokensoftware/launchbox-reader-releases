# Reading Documents

LaunchBox Reader adapts to different kinds of documents. A scanned manual, a comic archive, and an EPUB book do not need the same layout, so the reader gives you display options that fit each style.

## Moving Through Pages

Use the mouse, keyboard, controller, or progress control to move through a document.

Common ways to navigate:

- Next page or spread
- Previous page or spread
- Scroll continuous documents
- Jump with the progress control
- Select an entry from the table of contents
- Select a bookmark

## Layouts

Fixed-layout documents, such as PDFs, comics, image archives, and image folders, can use page-based layouts.

Available layouts include:

- Single page
- Spread
- Stacked

Single page is useful for small screens or tall manual pages. Spread is useful for book-like reading. Stacked is useful when you want to scroll through pages continuously.

## Fit and Zoom

Fit options control how fixed-layout pages are sized in the reader.

- Fit: show the full page or spread.
- Fit width: fill the available width.
- Fit height: fill the available height.
- Free zoom: manually zoom in or out.

If a scanned page has borders or unusual dimensions, try a different fit mode or margin setting.

## Two-Page Scans

Some booklets and magazines are scanned one physical sheet at a time, so a
single image holds two book pages side by side. The reader detects those sheets
and splits them so each page fills its own side of the spread.

If a page is split when it should not be, or shown whole when it should be
split, change Split Sheets in Settings. See [Reader Settings](settings.html).

## Reflowable Books

EPUB, Word, text, and rich text documents are reflowable. Their text adapts to
the window size and reading settings rather than being fixed to a scanned page.

Options for reflowable books include:

- Single-page or two-page layout
- Font family
- Text size
- Line spacing
- Margins
- Theme

## Fullscreen Reading

Fullscreen is useful for couch reading, cabinet setups, and TV displays. You can toggle fullscreen from the reader chrome or with the configured keyboard/controller mapping.

## Closing the Reader

Close the reader when you are finished. Your reading position is saved so the document can resume from the same location next time.

Use Back when you want to leave an overlay and return focus to the reader controls. Use Close reader when you want to exit the reader.
