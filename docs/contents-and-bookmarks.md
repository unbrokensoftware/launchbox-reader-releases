# Contents and Bookmarks

The Contents panel helps you jump around a document. It can show a document-provided table of contents, your bookmarks, or both.

## Table of Contents

Some documents include a built-in table of contents. When one is available, LaunchBox Reader shows it in the Contents panel.

Use the table of contents to:

- Jump to chapters or sections.
- Move through long manuals faster.
- Return to reference sections without scrolling page by page.

Not every file includes table of contents data. Many scanned PDFs and image-based manuals are just pages with no section metadata.

## Bookmarks

Bookmarks are your own saved places in a document.

Use bookmarks for:

- Control reference pages.
- Password or map pages.
- Move lists.
- Strategy sections.
- Important diagrams.
- Any page you want to find again quickly.

## Adding a Bookmark

Open the document to the page or location you want to save, then use the bookmark action from the reader controls or your configured keyboard/controller mapping.

## Using a Bookmark

Open the Contents panel and select the bookmark. The reader jumps to that saved page or location.

## Renaming a Bookmark

Bookmarks can be renamed so they are easier to recognize later.

Good bookmark names are short and specific:

- `Controls`
- `Map`
- `Passwords`
- `Boss strategy`
- `Emeralds`

## Documents Without a Table of Contents

If a document does not provide a real table of contents, the Contents panel focuses on bookmarks instead of filling the panel with every page. This keeps the panel useful for the things you chose to save.
