# LaunchBox Reader

LaunchBox Reader is a free document reader from Unbroken Software for reading game manuals, guides, books, comics, and related documents.

This repository hosts public releases, release notes, and documentation for LaunchBox Reader. Source code is not published in this repository.

## Downloads

Public downloads will be available from the GitHub Releases page:

https://github.com/unbrokensoftware/launchbox-reader-releases/releases

## Documentation

Documentation lives in the `docs` folder and will grow alongside public releases.
