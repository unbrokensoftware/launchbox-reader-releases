# Changelog

## 1.0.0

Initial public release of LaunchBox Reader.

### Highlights

- Built-in reading for manuals, guides, comics, image folders, EPUB books, and text documents.
- Fast first-page loading with background document preparation.
- Persistent reading position and per-document preferences.
- Table of contents and bookmark support.
- Keyboard and controller navigation.
- Customizable keyboard and controller mappings.
- LaunchBox and Big Box integration.

### Supported Formats

- PDF
- EPUB
- CBZ, CBR, CB7, CBT
- ZIP, RAR, 7Z image archives
- Image folders
- JPG, JPEG, PNG, GIF, BMP, WEBP
- TXT, RTF
